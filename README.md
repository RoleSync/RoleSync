# RoleSync — Intelligent HRMS & Enterprise Management System

RoleSync is a modern, full-stack Human Resource Management System (HRMS) built for multi-tenant scalability, real-time employee self-service, intelligent attendance automation, leave management, payroll, performance reviews, and social engagement.

## 🚀 Key Modules
1. **Authentication & Multi-Tenancy**: Subdomain lookup, dual-mode login (Work Email / Employee Code), role-based access.
2. **Dashboard Overview**: Real-time punch timer counter, live clock in/out, weekly work hour analytics, leave balances, upcoming celebrations spotlight, and request status dials.
3. **Leave Management**: 6 quota buckets (Bereavement, Casual, Earned, LWP, Menstrual, Sick), Table vs Card view, requests filter bar, and mandatory/restricted holiday rosters.
4. **Time & Attendance**: 5 KPI metrics, daily 3-series interactive bar chart, bulk regularization, Shift calendar (General Shift 1120), FAQ modal, and 4 policy accordions (480-min shift deductions, No-Show auto-deductions, Comp-Off rules).
5. **Expense Management**: Multi-tab (Travel, Expenses, Advances), "Viewing as" delegate selector, 7-state approval filters.
6. **Performance & Feedback**: 1:1 meetings, OKR updates, continuous feedback, formal review cycles.
7. **Social Intranet & Recognition**: Anonymous/named composer, photo/video attachments, "Give A Badge" peer awards (Applause, Star Performer), interactive feed.
8. **Separation / Exit Management**: Multi-stage exit initiation, clearance checklists (IT, HR, Finance), 6-state lifecycle tracking.
9. **Alerts & Action Items**: Tabbed center separating general notifications from pending/archived approval actions.
10. **My Calendar**: Month/Week/Day switchers, Google Calendar OAuth sync, and color-coded event filters.
11. **People & Org Chart**: Dynamic hierarchy tree with manager node metrics, subordinate count badges, and searchable company directory.
